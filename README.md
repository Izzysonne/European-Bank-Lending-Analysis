# European Bank Lending Analysis

## 📖 Overview

This repository contains my Master's thesis completed as part of the Master of Science in Economics at Friedrich Schiller University Jena.

The project investigates the relationship between securitisation markets and bank lending in Europe using bank-level panel data and econometric analysis. The study combines multiple financial datasets, performs extensive data cleaning and preparation, and estimates panel regression models to examine how securitisation activity influences lending behaviour.

---

## 🎯 Research Question

**How does securitisation activity affect bank lending among European banks?**

---

## 📊 Data Sources

This project combines data from:

- BankFocus
- European Central Bank (ECB)
- Eurostat

> **Note:** The original datasets are not included in this repository because they are subject to licensing restrictions.

---

## 🛠️ Methodology

The analysis includes:

- Data cleaning and preparation
- Merging multiple datasets
- Variable construction
- Descriptive statistics
- Fixed-effects panel regression models
- Robustness checks
- Data visualisation
