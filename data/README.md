# Data

The raw datasets used in this project are not included in this repository due to licensing restrictions.

## Data sources

### BankFocus
Provider: Bureau van Dijk (Moody's)

Variables include:

- Total assets
- Total equity
- Corporate loans
- Mortgage loans
- Consumer loans
- Deposits
- Tier 1 capital
- Risk-weighted assets
- NPL ratio
- ROA
- ROE

### ECB Financial Vehicle Corporation (FVC) Statistics

https://data.ecb.europa.eu

Used to construct:

- Securitisation issuance
- Securitisation stock
- Stock-to-GDP ratio

### Eurostat

https://ec.europa.eu/eurostat

Macroeconomic controls:

- GDP
- GDP growth
- Unemployment rate

The analysis scripts reproduce the empirical results once the original datasets are placed inside the `data/` directory.
